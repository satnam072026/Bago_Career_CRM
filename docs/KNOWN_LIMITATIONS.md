# Known Limitations & Honest Disclosure

1. **Microsoft Graph Live Connection**: The current execution runtime does not have an authenticated Microsoft Entra ID / OneDrive OAuth token attached (`0` Microsoft Graph accounts connected). However, Sandeep's local `C:\Users\bagos\OneDrive\Documents` folder is mirrored into Google Drive under `My Laptop / Documents` (`folderProperties.syncedComputer = true`), allowing us to discover and index his `.xlsx` workbooks (`Jober_Anti`, `Test Website`, `BusinessLending_Private_Lead_Tracker.xlsx`) via Google Drive API.
2. **Viewer History Availability (`viewedByMeTime`)**: Google Drive API exposes `viewedByMeTime` for the authenticated user (`bagosandeep@gmail.com`), which was present on `68` of the `73` October-active workbooks and absent (`null`) on `5` workbooks (including shared files from `papakattu@gmail.com`). Where absent, the UI and CSV explicitly record `Not available from provider`.
3. **Six 0-Byte `.xlsx` Files in `All_Excel_Files_2026-10-09`**: Six `.xlsx` files uploaded on `2026-10-09` have `fileSize = 0` in Google Drive (`Europe_Jobs_Shortlist_2026-09-25.xlsx`, `Scotland_Ireland_Jobs_Shortlist_2026-09-22.xlsx`, `Baltic_Jobs_Shortlist_2026-09-20.xlsx`, `EU_Jobs_MASTER_2026-09-29.xlsx`, `Italy_Jobs_2026-09-29.xlsx`, `Cyprus_Jobs_September_2026.xlsx`). These are flagged as `Error (0-Byte / Empty .xlsx File)` in the workspace rather than silently ignored.
